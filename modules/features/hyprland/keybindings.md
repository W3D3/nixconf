# Hyprland Keybindings

Modifier key: `Super` (Windows key)

## Navigation

| Keybind | Action |
|---|---|
| `Super + h/l` | Focus window left/right (crosses monitors) |
| `Super + j/k` | Focus window down/up |
| `Super + Shift + h/l` | Swap columns left/right |

## Windows

| Keybind | Action |
|---|---|
| `Super + Backspace` | Close window |
| `Super + b` or `Super + f` | Toggle fullscreen |
| `Super + Space` | Toggle float |

## Workspaces

| Keybind | Action |
|---|---|
| `Super + q/w/e/r/t/y/u/i/o/p` | Switch to workspace 1–10 |
| `Super + Shift + q/w/.../p` | Move window to workspace 1–10 (no follow) |
| `Super + -` | Toggle scratch workspace |
| `Super + Shift + -` | Move window to scratch workspace |
| `Super + m` | Toggle music special workspace |

## Apps

| Keybind | Action |
|---|---|
| `Super + Return` | Terminal (Kitty) |
| `Super + d` | App launcher (otter-launcher) |
| `Super + f` | Chrome |
| `Super + s` | File browser (Nemo) |
| `Super + v` | Clipboard history picker (fuzzel) |

## Misc

| Keybind | Action |
|---|---|
| `Super + Shift + s` | Screenshot (copy selection) |
| `Super + a` or `Super + e` | Logout menu |
| `Super + z` | Toggle recording mode (show keypresses) |
| `Super + drag (mouse1)` | Move window |
| `Super + Shift + drag (mouse1)` | Resize window |
